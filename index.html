Algorithms & Data Structures · Flagship Java 17 · JavaFX 21

RouteWise — Delivery Route & Logistics Optimization Platform

RouteWise is an advanced desktop application built to solve real-world urban delivery and logistics challenges across Sri Lanka. The platform models Sri Lankan road networks as a weighted graph and computes optimal turn-by-turn delivery routes using Dijkstra's Algorithm with a custom Min-Heap Priority Queue — dynamically factoring in live traffic congestion levels (Normal / Moderate / Heavy).

  • Custom Min-Heap Dijkstra Engine: All core algorithms and data structures built entirely from scratch without standard Java Collections.
  • Binary Search Tree (BST): Implements O(log n) package tracking and in-order traversal for inventory management.
  • QuickSort Engine: Prioritizes orders dynamically based on package urgency score and emergency status.
  • Doubly & Circular Linked Lists: Powers step-by-step turn navigation and continuous 24/7 patrol shift simulations.
  • Real-Time Big-O Benchmarking: Features a live execution performance workbench comparing custom structures against native Java collections.
  • Dynamic Canvas UI: Interactive Sri Lanka delivery network map with animated delivery truck and Glassmorphism design.

Automatic Coconut Husking System • Hardware Prototype

Automatic Coconut Husking & Sorting Control System

Engineered an automated agricultural processing and control system for the Robotics Application Developments module at NIBM. Designed to eliminate high-risk manual dehusking, increase throughput, and monitor production yields in real time.

  • Servo Guiding Unit: Metal gear servo motor swings coconuts steadily into spiked husking rollers for consistent alignment.
  • IR Yield Counter: Infrared obstacle sensor detects each de-husked coconut entering the collection basket with debouncing logic.
  • I2C Telemetry: LM016L 16x2 LCD display driven via PCF8574 expander showing real-time coconut count and system operational states.
  • Audio-Visual Safety: Multi-color status LEDs and buzzer alert operators of process stages and full collection bins.
  • Safety Isolation: Decoupled high-power external roller motor from low-voltage Arduino microcontroller for maximum electrical safety.
